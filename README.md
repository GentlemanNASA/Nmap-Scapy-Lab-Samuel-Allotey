# Nmap & Scapy Lab

A documented hands-on lab covering host discovery, service enumeration, OS fingerprinting, SMB scanning, and packet-level analysis using Nmap and Scapy on an internal penetration testing network.

Conducted as part of the ParoCyber ethical hacking program.

---

## Objectives

- Perform host discovery and live host identification on a subnet
- Enumerate running services and detect operating systems
- Scan and enumerate SMB shares on a target host
- Craft, sniff, and analyze network packets using Scapy
- Observe ICMP traffic at the packet level

## Part 1: Nmap

### Host discovery

```bash
nmap -sn 10.6.6.0/24
```

Ping sweep to identify all live hosts on the subnet without port scanning.

---

### OS detection

```bash
sudo nmap -O 10.6.6.23
```

Uses TCP/IP stack fingerprinting to identify the target's operating system.

---

### Service enumeration on port 21

```bash
nmap -p21 -sV -A -T4 10.6.6.23
```

Identifies the service on port 21, detects its version, and runs aggressive detection scripts.

---

### SMB port scan

```bash
nmap -A -p139,445 10.6.6.23
```

Enumerates SMB services on the standard ports and gathers OS/network context.

---

### SMB share enumeration

```bash
nmap --script smb-enum-shares.nse -p445 10.6.6.23
```

Uses an NSE script to list available SMB shares on the target.

---

### Manual SMB verification

```bash
smbclient //10.6.6.23/print$ -N
```

Confirms discovered share access without credentials (null session).

---

### Supporting commands

```bash
ifconfig
ip route
cat /etc/resolv.conf
```

Used to document the lab network interface, routing table, and DNS configuration.

---

### Packet capture

```bash
sudo tcpdump -i eth0 -s 0 -w capture.pcap
```

Captures all packets during the scan session for offline analysis.

## Part 2: Scapy

### Starting Scapy

```bash
sudo su
scapy
```

---

### Basic packet sniffing

```python
sniff()
```

Captures all packets on the default interface. Traffic was generated in a separate terminal using `ping google.com`.

```python
paro = _
paro.summary()
```

Stores and summarizes the captured session.

---

### Interface-specific sniffing

```python
sniff(iface="br-internal")
```

Captures traffic on the internal lab interface. Traffic was generated by pinging the internal gateway and browsing to the target host.

```python
paro2 = _
paro2.summary()
```

---

### ICMP-filtered capture

```python
sniff(iface="br-internal", filter="icmp", count=5)
```

Captures exactly five ICMP packets, isolating ping traffic from all other activity.

```python
paro3 = _
paro3.summary()
paro3[3]       # Inspect a specific packet
```
